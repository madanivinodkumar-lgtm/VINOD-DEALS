VINOD DEALS — FREE AFFILIATE WEBSITE STARTER

FILES
- index.html: responsive product-card website with search, category filters and Buy buttons.

PREVIEW
1. Extract the ZIP.
2. Double-click index.html to open it in Chrome.

BEFORE PUBLISHING
1. Sign in to Amazon Associates Central India: https://affiliate-program.amazon.in/
2. Create a Special Link for each product you want to recommend.
3. Open index.html in Notepad or another text editor.
4. In the `products` list near the bottom, replace demo titles/descriptions/categories and set each `affiliateUrl` to your real Special Link.
5. Do not invent prices or discounts. Add only images/content you are allowed to use under Amazon's current policies.
6. Keep the disclosure: “As an Amazon Associate I earn from qualifying purchases.”
7. Review Amazon India's current Operating Agreement and Participation Requirements before publishing.

FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository named `vinod-deals` (or another available name).
3. Upload `index.html` to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The public URL will be shown in Settings → Pages.
GitHub's interface may change. Hosting is free for eligible public repositories; review GitHub Pages terms.

IMPORTANT
- This starter is a static website; it does not automatically fetch Amazon catalog data or prices.
- A live website does not guarantee Amazon Associates approval or commissions.
- Add the website URL to your Associates account/site list if required and make sure it complies with Amazon's current rules.
